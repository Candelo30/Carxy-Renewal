{{ 'ORÍGENES' | translate }}

{{ 'De proyecto de estudio a plataforma 3D' | translate }}

{{ 'CARXY nació mucho antes de ser esta comunidad. Todo empezó como un proyecto formativo con una idea muy clara.' | translate }}

{{ 'CARXY comenzó como un proyecto de estudio en el SENA, dentro de la Tecnología en Análisis y Desarrollo de Software (ADSO 2673492). Originalmente, la idea fue pensada para el sector de talleres de vehículos: una plataforma para personalizar vehículos en 3D y visualizar las modificaciones antes de llevarlas a cabo.' | translate }}

{{ 'Detrás de esa primera versión hubo un equipo apasionado por el diseño y la lógica del proyecto. Luis Eduardo Candelo Riascos fue el diseñador y creador de la lógica que dio forma a Carxy desde sus cimientos, sentando las bases técnicas y conceptuales sobre las que, con el paso del tiempo, evolucionaría el proyecto.' | translate }}

{{ 'Lo que empezó como un ejercicio académico para cumplir con la etapa lectiva se transformó, poco a poco, en lo que hoy es CARXY: un editor 3D web abierto, pensado para que cualquier persona pueda crear, aprender, compartir y remixear sin barreras.' | translate }}
