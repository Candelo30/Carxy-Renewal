EL PROYECTO

¿De qué trata CARXY?

Un editor y una comunidad pensados para que el 3D deje de ser intimidante.

CARXY es un espacio de creación 3D que combina lo mejor de un editor de escritorio con la inmediatez de la web. Abres el navegador, añades formas, ajustas materiales y publicas tu escena para que otras personas la vean, la comenten o la remezclen.

El proyecto también es una forma de aprender: cada publicación puede abrirse en el editor, así que puedes descubrir cómo está construida una escena y convertirla en el punto de partida de la tuya.

  • ✓ Editor 3D con primitivas, materiales y transformaciones.
  • ✓ Publicaciones con vista previa, likes, comentarios y remixes.
  • ✓ Perfiles de creador, seguimiento, chat y notificaciones.
  • ✓ Moderación y reglas de seguridad para cuidar la comunidad.
